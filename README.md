# OtakuStream Enhanced

This version is a visual upgrade of the original OtakuStream V2.

## Included
- Redesigned hero section
- Trending anime row
- Improved anime cards and poster artwork using CSS (no copyrighted episode files)
- Ratings, genres and ranks
- Search and genre filters
- My List saved in browser localStorage
- Better preview modal with official trailer search
- Responsive mobile navigation
- Improved footer and layout
- Existing Privacy and Terms pages

## Publish on GitHub Pages
Replace the website files in your repository with the files in this ZIP. Keep:
- `index.html`
- `style.css`
- `script.js`
- `privacy.html`
- `terms.html`

Your GitHub Pages settings can remain:
- Branch: `main`
- Folder: `/(root)`

GitHub Pages should redeploy after the changes are committed.

## Important
This site is a discovery/preview website. It does not host or redistribute copyrighted anime episodes. Use official trailers and licensed streaming services.

For future monetization, check the age and account requirements of each advertising, affiliate, payment, or domain provider. If a service requires an adult account holder, use a parent/guardian rather than bypassing its rules.


## Episode player
The Watch Center includes a season/episode interface. The three FREE slots are intentionally empty until you add video IDs for content you own or are licensed/authorized to stream. Do not populate them with copyrighted anime episodes from unofficial sources. For YouTube embeds, use videos whose owners permit embedding and follow YouTube's current player/API policies.


## Official episode playback
The episode system includes three FREE authorized-playback slots. They are intentionally not populated with copyrighted episode files. For Naruto, the first three buttons point visitors to the official VIZ Media YouTube channel/search. If you obtain permission to embed a specific episode, add its authorized YouTube video ID to the corresponding `videoId` field in `script.js`; the episode will then play inside OtakuStream.
